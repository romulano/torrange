Conectar este aparelho

O Torrange não pede e-mail nem senha. Ele usa um token de 100 caracteres, que é seu e fica só neste computador.

  1. Abra torrange.com/aplicativos e copie o token (se ainda não houver um, gere ali mesmo).
  2. Cole o token abaixo.
  3. Volte ao site e clique em Permitir para este aparelho.

O token é uma senha: guarde-o como tal. Aqui ele é gravado cifrado pelo cofre do sistema e nunca aparece em log nem no arquivo de diagnóstico.
