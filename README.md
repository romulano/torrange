# Torrange

Cliente desktop do Torrange com qBittorrent e player mpv integrados.

## Download

Os instaladores estão publicados em **[Releases](https://github.com/romulano/torrange/releases/latest)**.

| Sistema | Arquivo |
| --- | --- |
| Windows (instalador) | `Torrange-Setup-1.0.0.exe` |
| Windows (portátil) | `Torrange-1.0.0-win.zip` |
| Linux (Debian/Ubuntu) | `torrange_1.0.0_amd64.deb` |
| Linux (universal) | `Torrange-1.0.0.AppImage` |

### Instalação no Linux

```bash
# Debian / Ubuntu
sudo dpkg -i torrange_1.0.0_amd64.deb
sudo apt-get install -f

# AppImage
chmod +x Torrange-1.0.0.AppImage
./Torrange-1.0.0.AppImage
```

### Instalação no Windows

Execute `Torrange-Setup-1.0.0.exe`. O instalador não é assinado, então o SmartScreen pode
exibir um aviso — clique em *Mais informações* → *Executar assim mesmo*.
